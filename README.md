# Sofia计算器

一个直接在浏览器中运行的单页计算器。页面把常用计算、斐波那契数列、生物节律曲线和概率尝试次数计算放在一起，无需安装后端服务或数据库。

## 功能

- 基本四则运算、括号、百分号、小数和平方根。
- 三角函数 `sin`、`cos`、`tan`，按角度制计算；支持常见特殊角度。
- 常用对数 `log10`，以及 π、e 常数。
- `MS`/`MR` 暂存和读取当前数值。
- 斐波那契数列：输入非负整数 n，点击 `Fib` 计算 F(n)。实现使用 2×2 矩阵快速幂，复杂度为 O(log n) 次矩阵乘法。代码允许 n 不超过 100,000,000；很大的结果会占用大量内存和时间，实际可计算规模取决于浏览器和设备。
- 生物节律：输入出生日期和目标日期，显示体力、情绪、智力三条曲线，并标出目标日期。曲线在目标日期前后各显示 21 天。
- 概率尝试次数：按独立重复试验模型，估算达到目标成功概率所需的最少次数。

## 运行

1. 下载或克隆本仓库。
2. 用 Edge、Chrome 或其他现代浏览器打开 `supercomputer1210_0.html`。
3. 基本计算和曲线绘制在当前页面中完成。计算表达式使用 Math.js 9.5.1；页面通过 cdnjs 加载该库，因此首次使用计算器功能时需要联网。

项目没有构建步骤，也不需要 Python、Flask、数据库或单独启动本地服务器。

## 使用说明

- 角度函数以度为单位。例如输入 `30` 后点击 `sin`，得到约 `0.5`。
- 斐波那契输入必须是 0 到 100,000,000 之间的整数。高位数结果可能使浏览器变慢或耗尽内存。
- 生物节律日期使用 `YYYYMMDD` 格式，例如 `19900101`。目标日期不能早于出生日期。
- “单事件概率最少次数”中，单次概率可输入小数（如 `0.02`）或百分数（如 `2`）；目标置信度请输入 0 到 1 之间的小数，默认值为 `0.999`。

## 关于生物节律

生物节律曲线根据 23 天、28 天、33 天的周期正弦函数绘制。这是一种流行理论，没有可靠科学证据证明它能预测个人状态。结果仅供娱乐参考，不应用于健康、工作或其他重要决策。

## 隐私与依赖

页面不会把输入的日期或计算内容提交到本项目的服务器；本项目没有服务器端代码。浏览器会从 cdnjs 加载 Math.js，具体网络请求由浏览器向该 CDN 发起。Math.js 是独立的第三方依赖，按其自身许可证发布。
